Robotique mobile avec ROS2, Python et Gazebo

Présentation

Projet de robotique mobile réalisé dans le cadre de ma formation en Licence Systèmes Embarqués.

L'objectif est d'étudier la navigation d'un robot mobile dans un environnement simulé à l'aide de ROS2, Python et Gazebo.

Technologies utilisées

- ROS2
- Python
- Ubuntu 22.04
- Gazebo
- TurtleBot3
- VirtualBox

Travaux réalisés

- Création d'un environnement de simulation avec labyrinthe.
- Manipulation des nœuds ROS2.
- Utilisation du topic "/cmd_vel" pour commander les déplacements.
- Exploitation des données d'odométrie "/odom".
- Développement d'un script Python de navigation vers des coordonnées cibles.
- Étude de la simulation d'un robot mobile TurtleBot3.

Fichiers du projet

- "go_to_point.py" : programme Python de navigation.
- "build_maze.py" : génération du labyrinthe.
- "maze.world" : environnement Gazebo.
- "maze.pgm" et "maze.yaml" : carte du labyrinthe.
- "maze_sim.launch.py" : fichier de lancement de la simulation.

Compétences développées

Programmation Python, notions de robotique mobile, ROS2, communication entre nœuds, odométrie et simulation robotique.

Projet universitaire réalisé en environnement simulé.
